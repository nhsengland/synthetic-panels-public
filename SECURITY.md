# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please report them via one of the following:

- **GitHub Security Advisories**: Use the "Report a vulnerability" button on the [Security tab](../../security/advisories) of this repository.
- **Email**: Contact the NHS England Data Science & Applied AI team at [datascience@nhs.net](mailto:datascience@nhs.net) with details of the vulnerability.

### What to include

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Any relevant logs, screenshots, or proof-of-concept code

### What to expect

- We will acknowledge your report within 5 working days.
- We will provide an initial assessment within 10 working days.
- We will work with you to understand and resolve the issue before any public disclosure.

## Supported Versions

Only the latest version on the `main` branch is actively maintained.

## Scope

This policy applies to the code and configuration in this repository. It does not cover third-party dependencies or the Palantir Foundry platform, which have their own security processes.
